# 📰 Fake News Detection System

A Machine Learning based web application that detects whether a given news article is **Fake News or True News**.

## 📌 About the Project

Fake news is false or misleading information presented as news. This project uses **Machine Learning and Natural Language Processing (NLP)** techniques to analyze news articles and classify them as **Fake or True**.

The project processes news data, performs text preprocessing and uses Machine Learning techniques to generate a prediction.

A **Flask web application** provides a simple interface where users can enter news content and view the prediction result.
