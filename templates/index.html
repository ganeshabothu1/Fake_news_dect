ABOUT THE PROJECT

Fake News Detection System

This academic project demonstrates how Natural Language Processing and machine learning can be applied to news text classification.

The system processes news content, converts text into numerical features using TF-IDF, and uses a trained Logistic Regression model to classify the content into Fake News or True News.
