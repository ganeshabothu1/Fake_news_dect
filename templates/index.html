Performance Analysis

Logistic Regression achieved 98.65% accuracy on the text-based evaluation dataset. MobileNetV2 achieved 85% accuracy and CNN achieved 80% accuracy on the image-based evaluation dataset.

These models use different input modalities and evaluation datasets. Their accuracy values should not be treated as a direct like-for-like comparison.

ABOUT THE PROJECT

Fake News Detection Using Machine Learning and Deep Learning Techniques

This project develops an AI-powered web application that detects potentially fake news using both text-based Machine Learning and image-based Deep Learning techniques.

Machine Learning Approach

Logistic Regression is used for text-based news classification. Text preprocessing and TF-IDF feature extraction convert news content into numerical features for prediction.

Deep Learning Approach

The Deep Learning component uses two models: Convolutional Neural Network (CNN) and MobileNetV2. Both models analyze uploaded news-related images.

CNN Architecture

CNN uses convolutional layers, pooling operations and classification layers to learn visual features from news images.

MobileNetV2 Architecture

MobileNetV2 is a lightweight pretrained architecture. It uses depthwise separable convolutions to reduce computational requirements while extracting useful image features.

Model Evaluation

CNN and MobileNetV2 performance is compared using Accuracy, Precision, Recall, F1-score and ROC-AUC. Confusion matrices and ROC curves are also used for performance analysis.
